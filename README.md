One haiku about debugging, in the 5-7-5 syllable shape: a breakpoint holds its breath, a cursor blinks at three in the morning, and the bug turns out to be mine. Built for make.fun's "Seventeen Syllables of Debugging" bounty.

## Run it

```sh
node main.ts
```

This writes the haiku to `/output/entry.txt`.

The script checks the haiku is exactly 3 lines and 1–200 characters before writing.
